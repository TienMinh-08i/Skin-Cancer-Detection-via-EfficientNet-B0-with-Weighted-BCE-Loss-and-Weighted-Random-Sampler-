🔧 HOW THE SYSTEM WORKS
════════════════════════════════════════════════════════════════════════════════

CONFIG INHERITANCE:

  Step 1: Base Template (config_hpc.yaml)
          ↓ Has all default settings
          
  Step 2: Experiment Definitions (experiments.yaml)
          ↓ Specifies what's DIFFERENT for each experiment
          
  Step 3: Config Generator (generate_experiments.py)
          ↓ Merges base + definitions
          
  Step 4: Generated Configs (config_E1.yaml through config_E15.yaml)
          ↓ Each has complete configuration
          
  Step 5: Training Script (main_train.py)
          ↓ Loads config_E*.yaml and trains
          
  Step 6: Result Collection (run_all_experiments.py)
          ↓ Gathers metrics from all experiments
          
  Step 7: Paper Tables (generate_latex_tables.py)
          ↓ Creates LaTeX for publication


EXAMPLE: How E1 and E5 Differ

  E1 Config:
    model_name: efficientnet_b0
    loss_type: bce                    ← E1 differs here
    weighted_sampler_enabled: false   ← E1 differs here
    batch_size: 8                     ← Same as E5
    learning_rate: 0.0003            ← Same as E5
    num_epochs: 20                    ← Same as E5
    
  E5 Config:
    model_name: efficientnet_b0
    loss_type: cb_focal               ← E5 differs here
    weighted_sampler_enabled: true    ← E5 differs here
    batch_size: 8                     ← Same as E1
    learning_rate: 0.0003            ← Same as E1
    num_epochs: 20                    ← Same as E1
    
  → Fair comparison: only model, loss, and sampler differ
  → All other hyperparameters identical

🏆 METRICS TRACKED
════════════════════════════════════════════════════════════════════════════════

For each experiment:

  ✓ ROC-AUC (Area Under ROC Curve)
    → Overall discrimination ability
    
  ✓ AUPRC (Area Under Precision-Recall Curve)
    → Performance with imbalanced data
    
  ✓ F1-Score
    → Harmonic mean of precision and recall
    
  ✓ Sensitivity (True Positive Rate)
    → How many positive cases detected
    
  ✓ Specificity (True Negative Rate)
    → How many negative cases correctly identified
    
  ✓ Accuracy
    → Overall correctness

All metrics include:
  - Mean value across CV folds
  - Standard deviation
